## v3.4 콘셉트 카드 필드

기존 v3.3 콘셉트 카드 위에 다음 필드가 활용 가능합니다 (선택적).

```json
{
  "formula_main": "운명적_인연물",
  "formula_sub": "버디러브_5단계",
  "movement_code": "빙의",
  "narrative_motifs": ["옛 연인의 출현", "운명적 사랑", "삼각관계"],
  "first_scene_type": "의문유발형",
  "primary_crisis_ep": 28,
  "secondary_crisis_ep": 40,
  "target_consumption_tier": ["매니아", "오타쿠"],
  "target_age_distribution": "OTT_시리즈_전환_고려",
  "heroine_name": "한시호"
}
```

캐릭터 바이블에는 다음 필드가 추가됩니다.

```json
{
  "narrative_role": "전사_정신적_스승",
  "propp_archetype": "마법을 부리는 조력자",
  "vogler_archetype": "멘토",
  "moe_attributes": ["역할:신비한_단골손님", "성격:쿨데레"]
}
```

이 필드들은 v3.4 5종 블록 + A19·A20·A21 룰의 입력으로 사용됩니다. 비어있으면 v3.3과 동일하게 동작하므로 호환성 문제는 없습니다.

## 핵심 원칙

1. **기획↔집필 강제 연결** — 기획에서 정한 모든 재료가 회차 집필 프롬프트에 자동 주입
2. **시장 검증** — 5대 결정 요인(인기/소재/장르/평점/가격)이 회차마다 강제 충족
3. **캐릭터 평면화 방지** — 9종 인물 역할 + 학술 원형 매핑으로 다중 인물 등장 회차에서 식별성 확보
4. **마음 흐름 일관성** — 회차별 단계 자동 추론으로 작품 전체의 정서적 흐름 유지
5. **여성향/남성향 발란스** — 양쪽 동등 지원 (마음 흐름 5단계 vs 완성된 영웅 3단계)
6. **학술 표준 강제** — 한국 로맨스 27편 검증된 안좋은첫인상-한공간 플롯 + 1차/2차 위기 + 첫 장면 9유형 (v3.4 신규)

## v3.5 업데이트 — 계측기 문체 차단

인물의 지각·행동을 초·미터 단위로 계측하는 문체를 차단합니다.

> ❌ "그는 세 방향을 각각 1.5초씩 훑었다"
> ✅ "그는 세 방향을 차례로 쓸어봤다"

- **A22. 수치 정밀 표현 금지** — 본문 집필 프롬프트에 강제 주입.
  3단 심각도 + 환원 예시표 8쌍 + 직업적 예외 조항(저격수·의사 등 회차당 2회 이내)
- **NUMERIC_PRECISION 12번째 자가 검수 축** — 검출 시 환원 제안 동반 출력.
  시각·층수·나이·금액은 예외 처리
- 가중치: 19금·듀얼 0.05 / 15금 0.08
